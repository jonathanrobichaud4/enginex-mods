rekordbox

Runs the XDJ-RX3 rekordbox player on this deck, using rblive4. Engine stops while it runs and starts again when you quit.

...

To quit from the deck, hold SHIFT and BACK together for two seconds.

Setting it up

  1. On your computer, get the rekordbox folder of the enginex-mods repo and run
    python3 make-rekordbox-pack.py /path/to/extracted
    It needs only Python 3, on Windows, macOS or Linux. The folder is your own extracted XDJ-RX3 v1.20 files (rblive4 explains the layout); nothing from Pioneer comes with this mod.
  2. Give the deck the rekordbox-pack.tgz it makes, either way:
    • put it on a USB drive, plug the drive into the deck and press Set up in Settings > ABOUT / UPDATE, or
    • upload it here:
  3. Press Start.
